The same records form two different graphs

The binary graph links entries that share exact recorded motifs. The topic graph links entries with similar 15-factor semantic profiles. The node set is held constant; representation, edge construction, and Leiden resolution are not.

Display rule. The topic view draws all 8,854 released union-kNN links. The binary graph has 358,966 positive-Jaccard links and is too dense to draw legibly, so its view uses the reproducible union of each node’s six strongest incident links (4,113 released edges). Layout distance helps reveal structure but is not itself a similarity measure.
